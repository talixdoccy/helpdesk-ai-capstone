# Software Installation Guide

## Issue
The user says a software application will not install, fails during setup, or shows a permission error.

## Basic Troubleshooting Steps
1. Confirm the user downloaded the correct installer.
2. Check whether the user has permission to install software on the device.
3. Ask the user to close other programs before trying again.
4. Restart the computer and retry the installation.
5. Check whether antivirus or security settings may be blocking the installer.
6. Verify that the device has enough storage space.
7. If the installation still fails, escalate the issue to IT support.

## Recommended Helpdesk Response
If a user cannot install software, first confirm that the correct installer is being used and that the device allows software installation. Ask the user to restart the device and try again. If the issue continues, escalate the case for further investigation.

## Escalation Conditions
Escalate the case if:
- the installer fails repeatedly
- the user lacks permissions
- security settings or company policy block the installation
