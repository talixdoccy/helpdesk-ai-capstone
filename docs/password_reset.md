# Password Reset Guide

## Issue
The user cannot log in to their account or says they forgot their password.

## Basic Troubleshooting Steps
1. Ask the user to confirm their username or email address.
2. Check whether Caps Lock is turned on.
3. Ask whether the user is receiving an "incorrect password" or "account locked" message.
4. If the password is forgotten, direct the user to the password reset page.
5. If the account is locked after multiple failed attempts, wait a few minutes and try again.
6. If the issue continues, escalate the case to the IT administrator.

## Recommended Helpdesk Response
If a user cannot log in, first confirm their username and whether the account is locked. If needed, guide the user through a password reset. If the reset does not work or the account remains locked, escalate the issue to support.

## Escalation Conditions
Escalate the case if:
- the reset email is not received
- the account remains locked
- the user no longer has access to the recovery email
