# Wi-Fi Connection Guide

## Issue
The user says they cannot connect to Wi-Fi, the connection drops often, or the internet is very slow.

## Basic Troubleshooting Steps
1. Confirm that Wi-Fi is turned on for the device.
2. Check whether other devices can connect to the same network.
3. Ask the user to disconnect and reconnect to the Wi-Fi network.
4. Restart the router if the issue affects the whole location.
5. Restart the user’s computer or phone.
6. Verify that the correct Wi-Fi password is being used.
7. If the problem continues, escalate the issue to network or IT support.

## Recommended Helpdesk Response
If a user cannot connect to Wi-Fi, first confirm that Wi-Fi is enabled and that the correct password is being used. Ask the user to reconnect to the network and restart the device if needed. If the issue continues or affects multiple users, escalate the case.

## Escalation Conditions
Escalate the case if:
- multiple users are affected
- the router restart does not solve the issue
- the connection fails repeatedly after basic troubleshooting
