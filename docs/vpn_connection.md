# VPN Connection Guide

## Issue
The user says the VPN is not connecting, disconnects frequently, or prevents access to company resources.

## Basic Troubleshooting Steps
1. Confirm the user is connected to the internet.
2. Ask the user to restart the VPN application.
3. Verify the username and password being used for VPN access.
4. Check whether the user is receiving a specific error message.
5. Restart the computer if the VPN client continues to fail.
6. If possible, test the connection on another network.
7. If the problem continues, escalate the issue to the network or IT support team.

## Recommended Helpdesk Response
If a user cannot connect to the VPN, first confirm internet connectivity and verify the login credentials. Ask the user to restart the VPN application and, if necessary, restart the computer. If the VPN still fails, escalate the issue for deeper investigation.

## Escalation Conditions
Escalate the case if:
- the VPN fails after credential verification
- the issue affects multiple users
- the VPN service may be unavailable
